# Security policy

## Reporting a vulnerability

For security issues in this profile repository or its generated site, visit
[GitHub Security Advisories](https://github.com/mohammadrezwankhan/mohammadrezwankhan/security/advisories)
and use **Report a vulnerability** if the repository offers that option.
If it is unavailable, request a verified private reporting channel from the
maintainer without including vulnerability details in the request. A public
issue requesting contact information is not itself a confidential channel.

Include the affected commit or page, the impact, and enough context for the
maintainer to investigate only once a private reporting channel is confirmed.
Use synthetic data and omit credentials, personal data, and confidential logs
from public issues and pull requests.

For security issues in a project linked from the profile, use that project's
own security reporting route.

## Supported revisions

Reports about the current default branch and the published profile site are in
scope. No response-time commitment is published.
