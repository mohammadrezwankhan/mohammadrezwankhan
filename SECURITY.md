# Security policy

## Reporting a vulnerability

For security issues in this profile repository or its generated site, open
[GitHub Security Advisories](https://github.com/mohammadrezwankhan/mohammadrezwankhan/security/advisories)
and select **Report a vulnerability**.

Include the affected commit or page, the impact, and enough context for the
maintainer to investigate. Use synthetic data and omit credentials, personal
data, and confidential logs. Keep vulnerability details out of public issues
and pull requests.

For security issues in a project linked from the profile, use that project's
own security reporting route.

## Supported revisions

Reports about the current default branch and the published profile site are in
scope.
