# GitHub profile makeover

## Intent

Make the existing engineering portfolio immediately identifiable and easier to explore, using a recognisable looping energy-core identity and coordinated social-preview art. Retain every existing asset and all substantive README content.

## Approach

Three approaches were considered: a large raster-animation replacement, a cosmetic change to the current teaching-first profile, and a lightweight SVG identity combined with a reordered evidence-led profile. The assistant selected the last approach under the user's instruction to do the work: it fits the supplied SVG reference, preserves the existing emblem, reduces transfer size, and exposes the strongest content. This selection was not a separate user design approval.

## Scope

- New animated avatar, banner, and poster counterparts; static upload-safe versions.
- A generated original companion artwork, supplementary to the compact vector assets.
- A readable profile introduction, six project routes, research links, and collaboration priorities.
- Existing detailed project evidence, learning guide, catalogue, and past art retained in organised expandable sections plus an exact original README snapshot.
- A small motion gallery under the existing GitHub Pages deployment, with pause and reduced-motion support.
- Repository social-preview uploads for the profile and six featured repositories, where the authenticated UI supports them.
- Refresh profile pins using the same evidence-based selection.

## Boundaries

Do not delete existing content, rewrite scientific claims, expose private repositories, modify project engines, change security/access, or bypass required CI. Native avatar and social-card animation are not assumed supported; ship static versions and verify actual platform behaviour.

## Verification

Compare the preserved snapshot byte-for-byte with the baseline. Check substantive-line and link retention, SVG safety and size, GIF loop metadata, PNG dimensions and sizes, local gallery interactions and reduced motion, README mobile rendering, the existing guide validation, and applicable remote CI. Publish only with known verification status.
