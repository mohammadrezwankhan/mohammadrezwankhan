## Animation and platform boundaries

GitHub's [profile requirements](https://docs.github.com/en/account-and-profile/reference/profile-reference) accept PNG, JPG, or GIF avatars under 1 MB and below 3000 × 3000 pixels, recommending about 500 × 500. Format acceptance does not promise animation. A [GitHub Community response](https://github.com/orgs/community/discussions/75239) explicitly states that animated GIF profile pictures are unsupported. The account therefore uses a static PNG; motion is supplied through the README/gallery assets.

GitHub [documents GIF support in profile READMEs](https://docs.github.com/en/account-and-profile/concepts/personal-profile). Each visitor's [accessibility preferences](https://docs.github.com/en/account-and-profile/how-tos/account-settings/managing-accessibility-settings) can control animated-image autoplay. The SVG masters are self-contained and provide reduced-motion alternatives; actual embedded playback must be checked on the destination surface.

[Repository social-preview guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview) recommends 1280 × 640 pixels and a PNG/JPG/GIF under 1 MB. The shipped social previews use opaque static PNGs for dependable sharing. A receiving social platform can cache or transform the image; animation is not promised there.
